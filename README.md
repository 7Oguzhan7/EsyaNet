# 🎒 EşyaNet — Kayıp Eşya Açık Artırma ve Bağış Otomasyon Sistemi

EşyaNet; Belediyeler, Emniyet Müdürlükleri ve Toplu Taşıma Kurumları için geliştirilmiş **Harita Destekli Kayıp Eşya Takip, Canlı Açık Artırma, İhtiyaç Sahibi Bağış Havuzu ve Resmi Tutanak Otomasyonu** web uygulamasıdır.

---

## 🌟 Öne Çıkan Özellikler

- 🌐 **Canlı Şube Haritası:** Teslim noktalarını (Zabıta, İETT, Emniyet) harita üzerinde canlı pinlerle görüntüleme.
- 🔍 **Akıllı Arama & AI Önerici:** Kayıp eşyaların kategori, konum ve akıllı eşleşme skorları ile bulunması.
- 📋 **Hak Sahipliği Başvurusu:** Kanıt yükleme ve şube teslimat randevuları takibi.
- 🔥 **Canlı Açık Artırma:** Sahibi çıkmayan eşyalara canlı teklif (pey) verme.
- 🎁 **İhtiyaç Sahibi Bağış Havuzu:** Ücretsiz bağış talebi oluşturma.
- 📄 **Resmi Teslim-Tesellüm Tutanağı (PDF/Yazdır):** Kurum yetkilileri için evrak kodu ve zaman damgalı tutanak üretimi.
- ☀️/🌙 **Dark & Light Mode:** Göz dostu tema desteği.

---

## 🛠️ Teknolojiler

- **Frontend:** React, Vite, Vanilla CSS (Glassmorphic UI), Leaflet Maps
- **Backend:** C# .NET 10 Web API, Entity Framework Core
- **Veritabanı:** PostgreSQL (BCrypt Hash şifreleme)
